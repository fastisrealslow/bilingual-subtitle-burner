# 林园干净成片流程

## 结论

“园园滚雪球”的干净感并非主要来自大面积去水印。对 `BV1iHdYYAEXe` 与
`BV155auz2EqA` 的公开试看抽样显示，它会把讲话音频放到重新制作的静态人物卡或
活动拼图上，再只加入自己的一套标题与字幕。这样天然不会残留原片硬字幕、台标和
搬运账号角标。

本项目不直接复制或发布竞品成片。竞品历史视频只作为溯源线索，用来识别值得找的
话题、完整场次和可能的一手来源。

## 新流水线

| 阶段 | 输入 | 输出/规则 |
|---|---|---|
| 参考入库 | `up_videos.json` 中标题含“林园”的条目 | `competitor_reference`；`source_role=reference`；禁止直接调度 |
| 原片优先 | 第一财经、主办方、上市公司、官方访谈/直播 | 优先 720p/1080p、完整音轨、无硬字幕版本 |
| 可清理原画 | 仅边缘硬字幕或小角标 | 安全裁切/小范围 `delogo`，渲染 24 秒预览后再次 OCR |
| 不可清理原画 | 大标题、双字幕、拼贴或核心区水印 | 保留经人物核验的原音频，重建 1280×720 品牌音频卡 |
| 统一包装 | 三种画面策略 | 自有字幕、响度标准化、右上角“园来滚雪球”水印 |
| 成片复检 | 编码后文件 | 音视频轨、分辨率、外部角标、内容指纹、人物证明、清理策略证明 |

## 质量门禁 v5

- `clean_strategy=direct`：原画无旧字幕、无外部角标。
- `clean_strategy=delogo`：只处理小面积稳定角标。
- `clean_strategy=crop` / `crop_delogo`：裁切后必须实渲染并通过旧字幕复检。
- `clean_strategy=audio_card`：原画无法安全清理，使用干净品牌画布；不伪装成现场画面。
- 所有策略都必须写入 `source_quality.json` 和成片 `meta.json`；旧 v4 成片不会混入待投队列。

## 授权与溯源

- 参考条目永远不等于转载授权。
- 投稿仍使用转载声明，并保留内部 `source_url`；公开视频简介不放原视频链接。
- 优先找到同场完整原始视频；只有画面不可用但讲话者已经多帧核验时，才允许音频卡重建。
