# 林园干净成片流程

## 结论

“园园滚雪球”的高产并非主要来自大面积去水印。2026-09-04 对 6 条公开成片的
实际播放器画面抽样显示，它会混用三种策略：

| 实际类型 | 画面处理 | 观察结果 |
|---|---|---|
| 干净横屏访谈 | 基本不裁，直接保留原画 | 原片硬字幕仍在，只新增右上角账号水印 |
| 已包装竖屏切片 | 9:16 原样上传 | 标题、原字幕、编辑署名均可能保留；桌面端黑边由 B站播放器产生 |
| 音频/不可用画面 | 9:16 静态重建 | 浅灰人物插画卡，或黑底活动照片拼图；顶部红黄标题、底部黄字黑边字幕 |

其中 `BV1iHdYYAEXe` 是浅灰人物插画卡，`BV155auz2EqA` 是黑底活动照片拼图；
`BV1MBu26KE31` 直接保留横屏采访硬字幕，`BV17BgdzcE8t` 则连二次编辑标题和署名
一起保留。因此它的优势是素材接受范围宽、竖屏包装一致，并不是“去字幕技术更强”。

本项目不直接复制或发布竞品成片。竞品历史视频只作为溯源线索，用来识别值得找的
话题、完整场次和可能的一手来源。

## 新流水线

| 阶段 | 输入 | 输出/规则 |
|---|---|---|
| 参考入库 | `up_videos.json` 中标题含“林园”的条目 | `competitor_reference`；`source_role=reference`；禁止直接调度 |
| 原片优先 | 第一财经、主办方、上市公司、官方访谈/直播 | 优先 720p/1080p、完整音轨、无硬字幕版本 |
| 可清理原画 | 仅边缘硬字幕或小角标 | 安全裁切/小范围 `delogo`，渲染 24 秒预览后再次 OCR |
| 不可清理原画 | 大标题、双字幕、拼贴或核心区水印 | 保留经人物核验的原音频，重建 720×1280 竖版品牌音频卡 |
| 统一包装 | 三种画面策略 | 自有字幕、响度标准化、右上角“园来滚雪球”水印 |
| 成片复检 | 编码后文件 | 音视频轨、分辨率、外部角标、内容指纹、人物证明、清理策略证明 |

## 质量门禁 v6

- `clean_strategy=direct`：原画无旧字幕、无外部角标。
- `clean_strategy=delogo`：只处理小面积稳定角标。
- `clean_strategy=crop` / `crop_delogo`：裁切后必须实渲染并通过旧字幕复检。
- `clean_strategy=audio_card`：原画无法安全清理，使用干净品牌画布；不伪装成现场画面。
- 安全裁切总量上限由 35% 收紧到 24%；超过上限转音频卡，避免为了去字切坏人物。
- 音频卡模板为 `portrait_editorial_v2`：浅暖灰竖版、红金标题、抽象人物/话筒视觉、
  黄字黑边字幕；不复制竞品插画或照片。
- 音频卡顶部标题直接取本条已选观点，不再只显示泛化场次名。
- 音频卡封面单独生成 1280×720 横版，不能拿 9:16 视频帧硬充 B站封面。
- 所有策略都必须写入 `source_quality.json` 和成片 `meta.json`；旧 v5 成片不会混入待投队列。

## 授权与溯源

- 参考条目永远不等于转载授权。
- 投稿仍使用转载声明，并保留内部 `source_url`；公开视频简介不放原视频链接。
- 优先找到同场完整原始视频；只有画面不可用但讲话者已经多帧核验时，才允许音频卡重建。
