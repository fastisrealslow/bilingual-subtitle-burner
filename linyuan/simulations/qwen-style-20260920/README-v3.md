## 实现与实际问题

由唯一排序、逐条理由取代打分同分取首项；随机打乱候选展示次序。选稿后独立核对，最多修正一次再核对，保留全部失败。V3.1 把真实园园参考标题仅提供给风格比较，生成只用字幕与风格规则；移除审核提示中的具体事实例子，并反馈引用证据不匹配问题。

误放行：素材1第2次把主持人转述胡锡进的“不割肉不亏”当成林园观点。误拒绝：素材3前两次对有嘉宾依据的“不投AI、判断易错”提出不充分的拒绝理由。修正可能新增错误，或声称修好了却保留错词（素材10第3次的“拍戏率”）。部分标题更像研究报告，未稳定保持用户认可的第二版口吻。

本轮不仅改了选稿，也改了生成提示并取消前置阅读摘要，因此不是单变量对照；不能将结果变化只归因于直接比较。下一步应保留第二版生成方式，只对选稿做单项验证。
