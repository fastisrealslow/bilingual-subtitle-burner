# 长期运行风险清单

面向「一年持续有效」的健壮性评估。

## 核心风险：静默失败

这是最危险的一类——**接口返回成功，但零数据**，系统不报错，你也发现不了。

实测确认的静默失败点：

| 场景 | 表现 | 已加防护 |
|------|------|---------|
| 腾讯 suid 失效 | `ret=0` 但 newslist 为空 | ✅ 统计每个 suid 产出，全零抛异常 |
| 网易标签 ID 变更 | 页面正常返回，无视频链接 | ✅ 零产出时抛异常并打印当前 ID |
| B站搜索缺 Referer | `code=0` 但 result 为空 | ✅ 主程序已带 Referer；巡检脚本已修 |

**应对**：`healthcheck.py` 每次运行探测 5 个关键接口，用「有无实际数据」而非
「HTTP 状态码」判定，异常时退出码非 0。

## 硬编码标识清单

系统依赖 6 处硬编码，平台改版即失效：

| 标识 | 值 | 失效影响 | 恢复方式 |
|------|-----|---------|---------|
| 腾讯发布方 suid ×4 | `8QMY3Hxd...` 等 | 该发布方内容抓不到 | 从已入库文章反查 `card.suid` |
| 网易关键词标签 | `679756ed` | 网易源归零 | 访问 money.163.com 搜索页取新 ID |
| 腾讯 platform | `101001` | **视频直链失效** | 抓包 v.qq.com 播放请求 |
| 腾讯 appver | `29_android_7.6.10` | 无影响（实测参数不敏感） | — |
| B站 UP 主 mid | `1700344493` | 对标数据失效 | 换人时改配置 |
| B站合集 season_id | 6 个 | 列表枚举失败 | `seasons_series_list` 重新获取 |

**故障注入实测**：改错 `appver` 仍正常；改错 `platform` 直接拿不到视频流；
改错 suid / 标签 ID 静默返回空。

## 会过期的东西

| 类型 | 有效期 | 处理 |
|------|--------|------|
| 微博 CDN 直链 | **1 小时** | 抓完必须立即下载（`run_all.sh` 已串联）|
| 抖音直链 | 数天 | 下载器 403 自动回源重解析 |
| 腾讯 vkey | 数天 | 同上，用 vid 重新换 |
| 好看 / 网易直链 | 长期稳定 | 无需处理 |
| B站 buvid cookie | 单次会话 | 每次运行重新获取 |

## 容量推演（一年）

| 项目 | 当前 | 日增 15 条/2 视频 | 阈值 |
|------|------|------------------|------|
| 数据库 | 0.7MB | ~9MB | 50MB |
| data.json | 0.4MB | ~5MB | **8MB**（前端一次性加载）|
| 视频库 | 9GB | **~25GB** | 40GB |

**data.json 是瓶颈**：前端全量加载，超过 8MB 会明显卡顿。
届时需改为分页加载或按时间窗口裁剪。

**视频库需要清理策略**：建议保留「股东大会现场 + 长视频」，
短切片定期归档到外部存储。

## 不会自愈的部分

**种子池不会自增长**。抖音/好看/网易靠种子驱动，发现新种子需要搜索引擎能力，
定时任务里调不到。`healthcheck.py` 会在种子超 45 天未更新时告警。

建议每月手动补一次，或用隔离子会话跑 `seed_refresh_task.md` 里的模板。

## 平台反爬演进风险（不可控）

| 平台 | 当前突破点 | 脆弱性 |
|------|-----------|--------|
| 抖音 | iesdouyin 分享页无防护 | 中——主站已有验证码，分享页可能跟进 |
| B站 | API 路径绕过 412 | 中——空间页已风控，API 可能收紧 |
| 微博 | passport 访客票据 | 中——m 站已拒绝访客，PC 站可能跟进 |
| 好看/网易 | 明文直链 | 低——长期无防护 |
| 巨潮 | 官方信披平台 | 极低——监管要求公开 |
| 雪球 | ❌ 未突破 | — |

**最稳的是巨潮**（股东大会公告），这也恰好是提前量的来源。
即使所有视频平台都失效，「提前 3 周知道会议时间地点」的能力仍然保留。

## 日常运维

```bash
# 每天
./run_all.sh

# 每周
python3 healthcheck.py    # 退出码非 0 说明接口异常
python3 backtest.py       # 验证核心能力未退化

# 每月
python3 fetch_up_list.py  # 刷新对标数据
# 补充种子池（见 seed_refresh_task.md）
```
