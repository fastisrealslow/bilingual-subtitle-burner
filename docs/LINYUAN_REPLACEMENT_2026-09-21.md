# 林园候选替换版

代码在 `codex/linyuan-reliability-packaging`，对应 [草稿 PR #40](https://github.com/fastisrealslow/bilingual-subtitle-burner/pull/40)。**这是已实现并持续验收的候选版；30% 出片目标与接近园园的整体质量尚未得到实测证明，不标记为已通过上线验收。** 未合并主线、部署或投稿。

## 此版交付什么

- 完整工程分支、工程快照 ZIP、相对主线的补丁和文件校验清单。
- [本地开发说明](LOCAL_DEVELOPMENT.md)：Python 3.11 环境及一条命令执行的离线回归；完整媒体依赖在 Linux Actions 验证。本机为 Intel i5、8GB 内存，未在本地安装和运行整套大模型生产服务。
- [实际成片对照页](../output/benchmark-20260921/comparison.html)：主线、优化版、对应园园参考，以及后续修复实片；封面使用各片实际生成的封面。媒体保留在本机 output 目录，工程 ZIP 不重复打包数 GB 视频。
- [16 种版式及封面实验](../output/benchmark-20260921/index.html)、20 条参考记录、模型实验原始结果和逐片问题记录。版式试样不计自动出片成绩。

## 核心行为变化

时长不再一律要求120秒。默认 `LINYUAN_CONTENT_POLICY=reference_v1`，20秒是技术下限，实际时长由完整原声边界决定；短观点、完整问答和长访谈分别记录。旧库存没有新策略证明时仍按旧规则验收。选源、生产、验收及投稿端共用此策略，不靠静帧、补音频或放慢原声凑时长。

选段区分正常口头语与标题文字要求；修复将主持人下一问带入片尾、合法竖画布被提前拒绝、镜头变化后沿用不合适固定框、原画不需裁切却被当作不可用等问题。来源半截大标题增加原图相邻字框与成片多帧检查；不能靠把来源文字切到无法识别而通过。

标题保留三个角度，合格候选可独立进入复核，一个坏候选不再拖垮整组。摘句回退绑定已确认的连续嘉宾原话，增加条件、数量范围、凭空新增审慎结尾、追加投入与无成本混淆、偏好与投资行动混淆检查。这些针对实测误判的检查不是通用语义正确性保证，原始模型调用和失败样本保留。

封面优先已核验的现场帧，再按文字排版回退；人物不清晰仍拒绝该帧，不以设计掩盖模糊。真人竖卡默认黑底、黄白标题，避免空白字幕框；现场横版保留对应路线。来源调度使用有界的近期实际记录，服务故障不惩罚来源；大陆中转不可用时不堵住可直达素材。

未默认换成9B或思考模式。已完成的15项配置实验没有证明它们更可靠：9B思考的完整片段组4/4生成超时，非思考组也有归属和含义错误。标题实验已独立为 Actions，可以单独重放原字幕，不必重跑下载、ASR和渲染。

## 如何比较与验收

9月24日凌晨的逐片复核现已覆盖26份冻结实片、22个素材编号，26份独立8B文案实验均已取回并逐条记录；完整100条新回归为 `35887065004`，仍未结束。后续返回的实片另按文件哈希记录，不能用“最新”覆盖已经更好的标题。同一母片重跑可能改选话题：49号本次改选风控，生产中间字幕虽然修正了“成瘾性”，但该词不在新成片中，不能说旧成片已修好。

标题还补上了实际46号发现的目标与回报混淆：原话“我要赚够一万倍”不能改成公司“能赚到一万倍”。可保留鲜明个人目标，不一律改成说教摘要或删掉强烈表述。8B/9B对象提取实验中，模型识别出“中石油”却给错句子编号，已改为程序逐字定位嘉宾原句；新的独立实验 `35894427585` 已完成：两种模型均写出中石油，但8B编造了“全球唯一所以没买”的因果，9B丢失了“如果”的假设；312号仍有对象泛化或含义压缩错误。因此不切换生产默认模型，并补上逐字对象、假设限定和原文没有“不值”判断时的拦截。

素材审计发现3、23、24、45、89号来自高度重合的同场采访。23号历史三片完成126个原声窗口匹配，89号仅第3片匹配；尚未解除历史去重，也不计为新增5份素材。该历史归档中还发现重复三次同一片段的旧视频，已与当前主线对跑区分记录。

本地对比页已有218个视频资源通过浏览器播放及中途跳转，并增加22个素材的实际标题、实际封面和下一步修改总表；后来新增资源仍逐个复查。新增统计批次使手机下拉框变宽，已限制宽度并重新检查390像素页面。离线开发回归462通过、1跳过，相关标题回归73通过。32号实片发现“垄垄断”“虽虽然”后，新增2026092401显示清理规则；43份历史字幕证明均可按旧规则重放。另生成完整190秒对照片，实际画面已看到这两处清理，音轨字节校验一致；该片是单独的显示修复演示，未重新执行全部生产画面闸门，不计新增素材。79号专项新成片确实显示了两处“复合增长”修复，但同次标题“医药行业不值”改坏原意，该新片未获编辑通过，优先展示之前较好的版本。

浏览器可播放、自动出片和编辑质量通过是三个不同结论；尚未证明整体达到30%或与园园齐平。

见 [主线对照说明](LINYUAN_MAIN_COMPARISON_2026-09-21.md)。主线代码与早期优化固定100对照为 [35548212133](https://github.com/fastisrealslow/bilingual-subtitle-burner/actions/runs/35548212133)；新版园园时长规则固定100为 [35557015452](https://github.com/fastisrealslow/bilingual-subtitle-burner/actions/runs/35557015452)。固定100均保持同一素材URL和发布历史，母片哈希相同才计算配对恢复或退步。后续小修与定向复跑另列，不把多个版本的最好结果拼成成功率。

素材库实验为73条待测候选中固定随机抽20条：[35556200021](https://github.com/fastisrealslow/bilingual-subtitle-burner/actions/runs/35556200021)。这轮已返回20份报告：3自动通过、16质量拒绝、1下载记录遗漏，自动通过率15%，未达30%。三条真实成片仍有需复核问题，不直接计为编辑合格。这是另一组素材，不与100条对照混算。质量拒绝、服务故障、缺失报告始终留在各自分母；任务完成、模型评分或产出MP4均不直接等于编辑质量通过。

逐片仍发现标题改写含义、片内来源文字残留、旧访谈时间未清楚呈现、长问题占比过高、字幕专有名词及单字断行等问题。已记录的问题不能因为新规则增加产量而被忽略。全片逐秒听音尚未完成，实取参考分辨率与平台标注也已分别记录。

## 替换方式与运行数据

优先通过该 PR 合并代码，保留主线不断更新的素材库、发布历史、库存、数据库和日志。当前候选已同步主线 `f794ce7` 的这些数据；后续主线若继续自动写入，应在实际替换前再次同步。工程 ZIP 是一个提交的完整快照，不能把其中的旧运行数据直接覆盖正在运行的系统。补丁只包含本轮与主线的差异，应用后先检查 `git diff --check` 并执行回归。

```bash
python3.11 -m venv .venv311
.venv311/bin/python -m pip install -r requirements-dev.txt
bash scripts/check_linyuan_local.sh
```

现有主线合并流程可能自动触发 FC 代码部署，应以现有 workflow 为准；这次没有执行该步骤。凭据、云函数配置、定时器与投稿配额保留原设置。阿里云此前实际返回欠费403，必须由账号侧恢复；它与素材质量拒绝分别统计。

需要暂时恢复旧长度时，将生产 Actions 和 FC 的 `LINYUAN_CONTENT_POLICY` 都设为 `legacy120`；不能只改其中一端。此设置只恢复时长规则，不回滚其他代码。`LIVE_CARD_THEME=light` 可恢复浅色真人卡。

以30%为验收目标时，应同时报告自动出片数、逐片质量通过数、故障类别与耗时，完成同一版本固定100测试后再作是否替换的判断。

42号聚焦实片 `35896658093` 已实际输出连续30秒，较原529秒电视报道减少旁白和多话题。但模型仍把原话改成“定价权才是真本事”。候选代码因此新增显式金句保留选项：先完成嘉宾归属阅读，再核对连续原句、限定、重复和排版；不能匹配就不以其他摘要冒充。原句路径在 `35900471003` 实际输出30秒视频，标题和封面均保留“垄断了好，我有定价权，我说了算”，字幕及选段与前版一致。封面随后发现三分句断在“我有”之后，已补按分句排版与96px三行几何检查。新排版将由完整批次再次验证。

99号专项 `35901097631` 已实际输出1146.44–1184.44秒完整38秒杠杆问答，标题与现场人像封面均为“杠杆不要加，不提倡”，保留后续限制与本人不加杠杆的选择。它替换同素材较差的收益标题，不计新增来源。42与99号均已作为三列表优先实片，其余历史问题和实验继续保留。目前218个视频资源完成浏览器播放与跳转检查，390px页面无横向溢出。

封面修复还包括忽略所选区间之外的母片最佳人像时间，并在现有样本模糊或未匹配时扩大到同片有界取样。身份阈值、60分清晰度下限与来源文字检查保持原标准。42号本地扩大取样仍未找到达标清晰帧，因此不声称已解决其资料照回退。
